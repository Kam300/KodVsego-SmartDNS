Smart DNS устанавливается только для текущего пользователя.

Программа появится в меню «Пуск» и списке установленных приложений Windows. Ярлык на рабочем столе можно выбрать на следующем шаге. Для самой установки права администратора не требуются; Windows запросит их при изменении DNS.

Настройки и резервные копии общие с вариантом без установки. Переустановка их не удаляет.

Перед удалением выключите DNS в программе, если хотите восстановить прежние настройки сети. Удаление программы само не меняет DNS и не удаляет резервные копии.
