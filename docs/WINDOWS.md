# Код Всего · Smart DNS для Windows

Опубликованная версия: **2.21.0**. Требуется Windows 10 2004+ или Windows 11, .NET Framework 4.8.

[Скачать EXE 2.21.0](https://github.com/Kam300/KodVsego-SmartDNS/releases/download/v2.21.0/KodVsego_SmartDNS.2.21.0.exe) · [Все релизы](https://github.com/Kam300/KodVsego-SmartDNS/releases) · [Общая инструкция](../README.md)

Канал: [Код Всего — @TotalC0de](https://t.me/TotalC0de). После C в адресе стоит цифра **0**.

Поддержка: [@TotalCodeAdmin](https://t.me/TotalCodeAdmin). Об ошибках также можно написать в [Issues](https://github.com/Kam300/KodVsego-SmartDNS/issues).

## Как пользоваться

1. Скачайте EXE и запустите. Установка не требуется.
2. Выберите провайдера. Стрелки и колесо мыши прокручивают список DNS.
3. Нажмите большую кнопку и подтвердите запрос администратора Windows.
4. Полностью перезапустите браузер или нужное приложение.
5. Для восстановления сохранённых настроек выключите DNS в программе.

Программа сохраняет исходные настройки адаптеров до изменения. Переключение провайдера эту копию не заменяет. При недоступном адаптере его копия остаётся для повторного восстановления. Неизвестные настройки, утраченные до создания копии, восстановить невозможно.

## Обычный и зашифрованный DNS

Обычный DNS доступен на поддерживаемых Windows 10 и 11. Системный DoH требует поддерживаемой Windows 11. Локальная DNS-служба для Windows 10 не устанавливается.

[Таблица провайдеров и адресов](../README.md#провайдеры). DoH доступен для Comss.one, GeoHide, Bezmezhau и DNS-AI. Для DoH Comss используется отдельный адрес 195.133.25.16. GeoHide EU и Xbox DNS в текущей версии работают без DoH. Для DNS-AI шифрование обязательно.

При включении системного DoH привязка IPv6 на изменяемых адаптерах временно приостанавливается; её исходное состояние сохраняется для восстановления. VPN может использовать собственный DNS и мешать работе. Проверка VPN приблизительная: расширения браузера, прокси и VPN на роутере могут не определяться.

## Antigravity

«Доп. DNS Antigravity» задаёт правила для cloudcode-pa.googleapis.com и daily-cloudcode-pa.googleapis.com. Для этой опции доступны GeoHide, GeoHide EU и Bezmezhau. GeoHide EU работает без шифрования. Comss для отдельной опции отключён. DNS-AI используется через общий системный DoH, без создания дополнительных правил.

После подтверждённого включения программа пытается перезапустить уже работающий Antigravity. Сохраните изменения заранее. Принудительное завершение процессов не выполняется.

При обнаружении прежних правил можно подтвердить замену с сохранением прежних DNS. Снятие галочки восстанавливает сохранённые настройки. Удаление известных старых правил — отдельная операция с предварительным экспортом в .reg; кнопка «Копия правил» открывает каталог копии. Чужие и организационные правила автоматически не удаляются.

Если включены только отдельные правила, основной DNS может быть выключен — интерфейс показывает «Только Antigravity». Настройка может помочь с ошибкой 400, но не гарантирует доступ к API или аккаунту.

## Что показывает тест DNS

Выберите провайдера в «Тест DNS» и нажмите «Проверить». Выбор в тесте не меняет настройки Windows. В обычном режиме проверяются ответы DNS-серверов, в зашифрованном — DNS-запросы через HTTPS. Для DNS-AI проверяются в том числе сайт Gemini и API.

**Успешный DNS-ответ не означает, что сайт или модель работают.** Доступность выданного адреса по HTTPS, DNS браузера и ограничения аккаунта — отдельные вопросы. У DNS-AI наблюдалась ситуация, когда DNS Gemini отвечал, а соединение с выданным узлом завершалось тайм-аутом.

Если сайты не открываются, проверьте подключение к сети, отключите VPN, проверьте собственный DNS браузера и перезапустите приложение. Можно попробовать другого провайдера или выключить DNS в программе для восстановления прежних настроек.

## Перезапуск браузера

Диалог после смены DNS позволяет выбрать браузер. Программа пытается сохранить используемые профили и закрыть браузер штатно. Сохраните работу заранее: приватные окна не восстанавливаются, фоновые процессы и запросы сохранения могут помешать перезапуску. Принудительное завершение не выполняется.

## Отчёт разработчику

При техническом сбое доступна кнопка «Сохранить отчёт». Сохраните TXT и вручную отправьте его [@TotalCodeAdmin](https://t.me/TotalCodeAdmin), описав действие и ошибку. Автоматической отправки нет.

Отмена прав администратора, отсутствие сети, VPN и другие обычные ситуации не требуют отчёта. В диагностике есть версия, сведения о Windows, DNS и правилах; история браузера, аккаунты, содержимое файлов и чатов не собираются. Перед отправкой можно открыть TXT и проверить его содержимое.
