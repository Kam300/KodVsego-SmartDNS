# Восстановление DNS отключённых адаптеров

В настройках **Общие → Очистить DNS…** выполняется предварительная проверка
всех перечисляемых Windows сетевых адаптеров, включая Wi-Fi без подключения.
Перед изменением показывается список: состояние адаптера, IPv4/IPv6, восстановление
сохранённой копии либо возврат известных DNS на автоматические.

Если есть копия, восстанавливаются исходные настройки DNS, сохранённые свойства
DoH/DoT и состояние привязки IPv6. Без копии автоматический DNS устанавливается
только у семейств, все статические адреса которых распознаны в каталоге программы
(включая сохранённые старые адреса). Смешанные адреса, стороннее шифрование и
настройки профилей Wi-Fi без копии не сбрасываются.

Адаптер без соединения остаётся доступным для восстановления, если Windows
предоставляет его интерфейс и разрешает запись. Полностью отсутствующее устройство
или ошибка записи не считаются успехом: копия сохраняется до повторной попытки.
Копии не удаляются ради видимости полной очистки. После операции выполняется новая
проверка и показываются оставшиеся записи.

Изменение выполняется через существующий защищённый процесс повышения прав,
общую блокировку DNS-операций и транзакционный механизм резервных копий.
Запущенный DNS приложения сначала нужно выключить; отсутствие интернета не
блокирует очистку. Выход из окна во время выполняющегося изменения блокируется,
чтобы не скрывать незавершённую операцию. Сетевые снимки и прежний результат
чекера сбрасываются перед восстановлением.

Обычное включение DNS продолжает менять только активные адаптеры. Исправление
распространяется на обнаружение оставшихся DNS без копии: раньше оно ошибочно
пропускало отключённые адаптеры. Восстановление существующих копий и раньше
использовало полный список интерфейсов.

Очистка не удаляет Wi-Fi-профили, приложения, драйверы или настройки IP-адресов.
