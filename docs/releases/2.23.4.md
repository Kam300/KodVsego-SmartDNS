При смене подключения Smart DNS сохраняет выбранного провайдера и режим шифрования. Пока приложение открыто, включая свёрнутое окно, после стабилизации новой сети программа применяет выбранный DNS и сохраняет исходные настройки нового адаптера отдельно.

- Убрано окно «Восстановление отложено». При выключении DNS доступные подключения восстанавливаются, копии отсутствующих адаптеров сохраняются. Если адаптер вернётся до закрытия программы, она попробует завершить восстановление.
- Автоматические изменения приостанавливаются при обнаружении VPN. Настройки, уже соответствующие выбранным, повторно не применяются. После отказа в правах или ошибки один и тот же набор подключений не вызывает повторных запросов. Права на новую настройку или восстановление Windows может запросить отдельно.
- Исправлена ложная блокировка DoH из-за точного локального правила для `slscr.update.microsoft.com`. Правило Windows Update сохраняется и отражается в интерфейсе и диагностике: его запросы могут использовать отдельный DNS. Неизвестные и организационные правила по-прежнему проверяются как конфликты.
- В режиме общего DoH карточка «Antigravity через DoH» показывает состояние подключения вместо лишней галочки и сообщения «Готово». Управление существующими отдельными правилами сохранено. Информационные сообщения получили соответствующий значок и подпись.
- MagicDNS доступен, GeoHide и GeoHide EU остаются временно отключены. «Авто» остаётся beta.

Файлы Windows:

- `KodVsego_SmartDNS.Setup.2.23.4.msi` — установка или обновление MSI-копии. Перед запуском закройте Smart DNS; удалять прежнюю MSI-версию для обновления не нужно.
- `KodVsego_SmartDNS.Portable.2.23.4.zip` — портативная версия с лицензиями.
- `KodVsego_SmartDNS.2.23.4.exe` — запуск без установки и обновление прежних EXE-копий.
- `SHA256SUMS.txt`, `release-files.json` — контрольные суммы и список файлов.

Обычный DNS: Windows 10 2004+ / Windows 11; системный DoH требует поддерживаемой Windows 11. MSI предназначен для x64. При окончательном удалении MSI программа восстанавливает сохранённые настройки сети; при обновлении настройки и резервные копии сохраняются.

Проверены логика Windows, интерфейс, команды повышения прав, состав EXE и структура MSI. Автоматические проверки смены сети используют тестовые адаптеры; переход между реальными Wi-Fi/Ethernet в ходе подготовки не проверялся. Отдельная служба не устанавливается, после закрытия программы подстройка сети и отложенное восстановление прекращаются.

Android APK в этот Windows-релиз не входит. Для выпуска подготовленной Android 1.5.1 нужен прежний ключ подписи. Инструкция второму разработчику: [android/RELEASE_1.5.1.md](https://github.com/Kam300/KodVsego-SmartDNS/blob/main/android/RELEASE_1.5.1.md).
