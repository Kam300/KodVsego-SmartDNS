Отменены изменения, добавленные в 2.23.4-test.3 и вошедшие в 2.23.4, которые автоматически применяли DNS при смене подключения и восстанавливали вернувшиеся адаптеры.

- Удалены обработчик смены Wi-Fi/адаптеров и его команды фонового изменения DNS. Возвращено поведение до test.3: включение, смена провайдера и восстановление выполняются по действию пользователя.
- Отменены изменения сообщений и обработки отложенного восстановления из test.3. Если адаптер недоступен, его копия остаётся для ручного восстановления.
- Сохранены существовавшие до этой функции резервные копии DNS каждого адаптера и восстановление DoH/IPv6. Новая версия не сбрасывает сетевые настройки при запуске и не удаляет сохранённые копии.
- Сохранены остальные исправления 2.23.4: проверка отдельного правила Windows Update при подключении DoH, карточка «Antigravity через DoH» и информационные значки.
- MagicDNS доступен; GeoHide и GeoHide EU остаются временно отключены. Режим «Авто» остаётся beta.

Файлы Windows:

- `KodVsego_SmartDNS.Setup.2.23.5.msi` — установка или обновление MSI-копии; перед запуском закройте Smart DNS. Удалять прежнюю MSI-версию для обновления не нужно.
- `KodVsego_SmartDNS.Portable.2.23.5.zip` — портативная версия с лицензиями.
- `KodVsego_SmartDNS.2.23.5.exe` — запуск без установки и обновление прежних EXE-копий.
- `SHA256SUMS.txt`, `release-files.json` — контрольные суммы и список файлов.

Проверены логика Windows, интерфейс, восстановление настроек, состав EXE и структура MSI. Низкоуровневые компоненты DNS и повышения прав возвращены к состоянию до функции смены сети. Проверки не меняли DNS компьютера и не переключали реальный Wi-Fi.

Системные DNS не сбрасываются самим обновлением. Если нужно вернуть исходные сетевые настройки, используйте выключение DNS в приложении. Android APK в этот Windows-релиз не входит, код Android не изменён.
