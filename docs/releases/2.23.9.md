# Windows 2.23.9 — обновление каталога DNS

## Что изменилось

- Общий каталог адресов DNS для Windows и Android. Приложение проверяет утверждённый каталог проекта при открытии, не чаще раза в сутки. В настройках есть галочка «Обновлять адреса DNS автоматически», статус и ручная проверка — без дополнительного окна.
- Новые данные сначала сохраняются в ожидании. Работующее подключение не меняется; применение происходит после выключения DNS и завершения восстановления резервных копий. Свои DNS Windows не перезаписываются.
- Проверяются формат, стабильные ID, публичные IP, HTTPS-адреса, известные типы чекеров и возрастающая версия. При ошибке используется сохранённая или встроенная копия.
- Обновлены адреса Comss.one и bootstrap для зашифрованных режимов; прежние адреса сохранены для распознавания старых настроек.
- Обновление адресов существующих маршрутов Antigravity сохраняет исторические идентификаторы и распознавание старых правил.
- Подготовлен наблюдатель официальных сайтов: он создаёт предложение для проверки через PR. Найденные адреса не распространяются автоматически без проверки разработчиком.

## Скачать

- `KodVsego_SmartDNS.Setup.2.23.9.msi` — установщик Windows.
- `KodVsego_SmartDNS.Portable.2.23.9.zip` — распаковать целиком; Wintun входит в комплект.
- `KodVsego_SmartDNS.2.23.9.exe` — один файл для способов 1 и 2. Экспериментальный способ 3 требует официальный `wintun.dll` 0.14.1 x64 рядом с EXE.
- `SHA256SUMS.txt` и `release-files.json` — контрольные суммы и состав пакетов.

Windows 10 2004+ / Windows 11, x64, .NET Framework 4.8. Перед обновлением закройте Smart DNS. MSI сохраняет настройки при обновлении; при удалении выполняет восстановление сетевых настроек.

Авто и экспериментальные способы по-прежнему beta. Успешная DNS-проверка не гарантирует доступ к аккаунту или ответ ИИ. Работающее подключение само не переключается из-за нового каталога.

## Android

Исходники Android 1.5.2 / versionCode 9 подготовлены: выбор шифрования, смена DNS, чекеры провайдеров, настройки и журнал, общий обновляемый каталог. Специальные функции Antigravity в Android не добавлены.

Стабильный APK 1.5.2 в этот выпуск не включён: его должен подписать владелец прежнего ключа Android 1.5.1. Тестовый APK с другой подписью не выдаётся за обновление. [Инструкция для второго разработчика](https://github.com/Kam300/KodVsego-SmartDNS/blob/main/android/RELEASE_1.5.2.md).

Новые файлы 2.23.9 не проверялись через VirusTotal; результаты старых сборок к ним не относятся.
