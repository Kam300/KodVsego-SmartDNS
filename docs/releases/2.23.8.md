# Windows 2.23.8 — автосмена DNS Antigravity и общий журнал

Автосмена помогает подобрать другой зашифрованный маршрут после повторных сетевых ошибок Antigravity. Она включается в настройках Antigravity и сохраняет отметку **beta**.

## Изменения

- Добавлен импорт новых ошибок `language_server.log` и `main.log` в общий журнал Smart DNS. Журнал можно скачать в настройках. Команды из предупреждений разрешений, ключи доступа, пути профиля и идентификаторы чатов скрываются.
- Автосмена распознаёт обрывы генерации, тайм-ауты запуска API и точную ошибку неподдерживаемого региона. Перегрузка модели, лимит запросов, ошибка авторизации и обычная серверная ошибка не вызывают смену DNS.
- Проверяются DoH и DoT, в том числе другой протокол того же провайдера. Проверка использует IP из каталога и проверку сертификатов. Ожидание HTTPS для Antigravity увеличено до 8 секунд на этап.
- Паузы после сбоев учитывают провайдера и протокол отдельно. Повторные сообщения об одном сбое соединения не считаются новыми ошибками. Подбор ограничен тремя попытками за десять минут.
- Если отдельный маршрут не помогает, Авто может сменить **основной DNS всего ПК**, сохранив отдельный DNS Antigravity. Перед этим проверяются адреса входа Google и DNS-ответы API. Эта проверка не выполняет вход или генерацию; после применения статус ожидает начало ответа клиента.
- Применение подтверждается локальным обработчиком. Ошибка применения сохраняет прежний маршрут. Отключение Авто или новый ответ клиента отменяют ещё не применённый результат поиска.
- Автоматические переключения проходят без всплывающих диалогов и без перезапуска Antigravity. Клиент со старым соединением может потребовать ручного перезапуска.
- Malw · CF остаётся доступен как общий DNS, но исключён из выбора отдельного маршрута и Авто Antigravity.
- Исходники Windows перенесены в `src/windows/`, скрипты — в тематические папки `tools/`; обновлены сборка, тесты и CI.

## Скачать

- `KodVsego_SmartDNS.Setup.2.23.8.msi` — установщик Windows.
- `KodVsego_SmartDNS.Portable.2.23.8.zip` — портативная версия, распаковать целиком; Wintun входит в комплект.
- `KodVsego_SmartDNS.2.23.8.exe` — один файл для способов 1 и 2; экспериментальный способ 3 требует официальный `wintun.dll` 0.14.1 x64 рядом с EXE.
- `SHA256SUMS.txt` и `release-files.json` — контрольные суммы и состав сборки.

Windows 10 2004+ / Windows 11, x64, .NET Framework 4.8. Перед обновлением закройте Smart DNS. MSI сохраняет настройки при обновлении; при удалении восстанавливает сетевые настройки.

## Проверки и ограничения

Проверены автоматические сценарии ошибок, подбора, отмены, подтверждений обработчика, сохранения прежних маршрутов и очистки журнала. Предварительная проверка Comss.one DoH с отдельным MagicDNS DoH прошла на текущем подключении без изменения DNS. Сквозная работа новой автоматической смены основного DNS с настоящим ответом Antigravity ещё не подтверждена.

Начало потока модели не подтверждает завершение ответа. DNS и официальный чекер не гарантируют доступ к аккаунту или генерацию. Авто работает, пока Smart DNS открыт, и может влиять на DNS других приложений. Автоматическая подстройка при смене сети не добавлялась.

Результаты VirusTotal для новых файлов пока не опубликованы. Старые результаты версии 2.23.7 не относятся к этим файлам.

Android APK 1.5.1 не переиздаётся. Общий каталог исходников учитывает исключение Malw · CF из цели Antigravity.
