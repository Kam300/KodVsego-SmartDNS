# Smart DNS 2.23.6-test.28

Предварительная версия для Windows. Стабильная версия — 2.23.5.

Выпуск объединяет изменения тестовой серии 2.23.6:

- На главном экране объединены способ подключения и шифрование: «1 · Через Windows», «2 · Через приложение», «3 · Gemini / NotebookLM», DoH · HTTPS и DoT · TLS. Меню поясняют назначение каждого варианта.
- В способе «Через приложение» работает локальный DNS на `127.0.0.1` / `::1`, доступен ручной подбор «Авто» и отдельный провайдер для двух API-доменов Antigravity. Программа должна оставаться открытой. Экспериментальный способ Gemini / NotebookLM использует DNS-адаптер; оба способа меняют DNS всего ПК, внешний IP не меняют.
- Каталог дополнен Zapret DNS, GeoHide US, Malw DNS, WLrus DNS, Webshift, AdGuard DNS и Malw CF. Параметры и заявленные сервисы хранятся в общем каталоге Windows/Android. Источники и ограничения описаны в [документации](../PROVIDER-SOURCES-2026-10-25.md). GeoHide RU/EU и Xbox остаются отключены.
- Карточка Antigravity учитывает заявленную поддержку выбранного провайдера: шифрование само по себе не означает поддержку Antigravity. Основной DNS и явно выбранный отдельный провайдер во втором способе независимы.
- Добавлены проверки сайта и API без авторизации, копирование результатов и технических сведений, сравнение фактического DNS через MangoProxy, выгрузка журнала текущего запуска в настройках. Успешный DNS/TLS/HTTP-ответ не подтверждает работу аккаунта или модели.
- Улучшены завершение локального DNS, восстановление настроек и диагностика ошибок канала. Программа не применяет DNS заново при смене Wi-Fi; управляемый режим останавливается и восстанавливает настройки при изменении сети.
- Полностью удалены ввод и чтение ключа Gemini, хранение ключа и запросы генерации с авторизацией. Проверки доступности не используют ключ и квоту модели.

## Файлы

- `KodVsego_SmartDNS.Setup.2.23.6-test.28.msi` — установщик Windows.
- `KodVsego_SmartDNS.Portable.2.23.6-test.28.zip` — портативный архив с лицензиями и документацией.
- `KodVsego_SmartDNS.2.23.6-test.28.exe` — отдельный исполняемый файл.
- `SHA256SUMS.txt` и `release-files.json` — контрольные суммы и описание файлов.

Перед обновлением выключите DNS в приложении и закройте работающую копию. Для MSI используйте новый MSI.

Android: обновлены исходники общего каталога для 1.5.2; APK в этот выпуск не входит. Подписание прежним ключом и отдельный выпуск выполняет разработчик Android: [инструкция](../../android/RELEASE_1.5.2.md).

## Проверки

Выполнены автоматические проверки Windows на подставных сетевых ответах и настройках, проверка структуры MSI без установки, проверка отсутствия удалённого кода ключа в EXE и визуальная проверка настроек и диагностики. Эти проверки не подтверждают доступность ИИ в каждой сети. Результатов VirusTotal для этой сборки пока нет.
