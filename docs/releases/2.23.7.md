# Smart DNS 2.23.7 для Windows

Стабильный выпуск: пользовательские DNS-провайдеры и исправления работы с Antigravity. Авто и экспериментальные способы подключения сохраняют отметку beta.

## Изменения

- В настройках можно добавлять, редактировать и удалять свои DNS: IPv4, необязательные IPv6, DoH и DoT. Изменения применяются после сохранения; редактирование используемого провайдера защищено. Пользовательские провайдеры доступны на главном экране и в Авто. Их поддержка конкретных ИИ-сервисов не подтверждается автоматически.
- Отдельный DNS для Antigravity переключается при работающем локальном DNS. Перед сменой проверяются оба API-домена, настройки сохраняются после подтверждения рабочего процесса. При ошибке прежний маршрут остаётся.
- Авто с целью Antigravity включает отдельный маршрут и предлагает перезапуск согласно настройкам. При переходе с системного DNS сначала восстанавливаются прежние настройки; ошибка восстановления останавливает переход.
- Добавлено отключаемое восстановление окна Antigravity при застревании на странице ошибки запуска. Программа ждёт двух успешных ответов проверенного локального Language Server и повторно загружает только страницу ошибки. Рабочие страницы не перезагружаются; число попыток ограничено. Функция работает, пока Smart DNS открыт, и не устраняет внутренние сбои Language Server или ограничения аккаунта.
- Уточнены состояния подключения, предупреждения VPN и поведение перезапуска Antigravity.

## Скачать

- `KodVsego_SmartDNS.Setup.2.23.7.msi` — установка и удаление через Windows.
- `KodVsego_SmartDNS.Portable.2.23.7.zip` — распаковать целиком; Wintun входит в комплект.
- `KodVsego_SmartDNS.2.23.7.exe` — отдельный файл; способы 1 и 2 доступны сразу. Для экспериментального способа 3 нужен официальный `wintun.dll` 0.14.1 x64 рядом с EXE.
- `SHA256SUMS.txt` и `release-files.json` — контрольные суммы и состав сборки.

Windows 10 2004+ / Windows 11, x64, .NET Framework 4.8. Перед обновлением закройте Smart DNS. MSI сохраняет настройки при обновлении; при удалении выполняется восстановление сетевых настроек.

## Проверка и ограничения

Автоматические тесты проверяют логику переключения, резервные копии, хранение пользовательских провайдеров, IPC и восстановление страницы на подставных сценариях. MSI проверяется без установки. На настоящем Antigravity проверены чтение состояния и готовность локального HTTPS-сервера. Автоматическое восстановление настоящего зависшего окна не воспроизведено сквозным тестом: при контрольном запуске окно загрузилось самостоятельно.

DNS-ответ и результат чекера не гарантируют вход в аккаунт или ответ модели. Автоматическая подстройка при смене сети не добавлялась. Android и APK 1.5.1 в этом выпуске не изменены.
