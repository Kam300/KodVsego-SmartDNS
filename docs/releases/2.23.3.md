MagicDNS теперь можно выбрать для Antigravity: доступны отдельные DNS-правила и автоподбор с проверкой обоих API-доменов. Для шифрованного подключения выберите MagicDNS, включите «Зашифрованный DNS» и подключитесь большой кнопкой — используется общий DoH. Старые отдельные правила нужно предварительно отключить для полного шифрования.

- GeoHide и GeoHide EU временно отключены: убраны из выбора, Авто и новых включений отдельных правил Antigravity. Прежние настройки распознаются для отключения и восстановления; при запуске сетевые настройки автоматически не перезаписываются.
- Перезапуск Antigravity Desktop ждёт завершения его сервера, процессов отображения и GPU. Если приложение не завершилось за 30 секунд, повторный запуск отменяется с пояснением. Принудительное завершение процессов не выполняется.
- Исправлено чтение сторонних DNS-правил с нестандартными именами: они учитываются при проверке конфликтов и не удаляются автоматически.
- Обновлён общий каталог Windows/Android. Режим «Авто» по-прежнему помечен beta.

Файлы Windows:

- `KodVsego_SmartDNS.Setup.2.23.3.msi` — установка или обновление MSI-копии. Перед запуском закройте Smart DNS; удалять прежнюю MSI-версию для обновления не нужно.
- `KodVsego_SmartDNS.Portable.2.23.3.zip` — портативная версия с лицензиями.
- `KodVsego_SmartDNS.2.23.3.exe` — запуск без установки и обновление прежних EXE-копий.
- `SHA256SUMS.txt`, `release-files.json` — контрольные суммы и список файлов.

Обычный DNS: Windows 10 2004+ / Windows 11; системный DoH требует поддерживаемой Windows 11. Установщик MSI предназначен для x64. При окончательном удалении MSI программа восстанавливает сохранённые настройки сети; при обновлении настройки и резервные копии сохраняются.

Проверены логика Windows, интерфейс, восстановление настроек, команды обновления, состав EXE и структура MSI. Сетевая проверка обоих IP MagicDNS через DoH и HTTPS для обоих API-доменов Antigravity прошла. Проверка DNS и соединения не подтверждает вход в аккаунт или работу модели.

Android в этот Windows-релиз не входит. Исходники Android 1.5.1 подготовлены, но для обновления основной Android-версии требуется прежний ключ подписи. Отдельный тестовый APK не заменяет основной Android-релиз.
