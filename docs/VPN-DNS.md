# Windows: DNS вместе с VPN (test.9)

1. Подключить VPN обычным способом.
2. В Smart DNS открыть «Настройки → Общие», включить «Совместимость с VPN · способ 2 · beta», сохранить.
3. На главном экране выбрать «2 · Через приложение», провайдера и DoH либо DoT, включить DNS.

Режим создаёт одно собственное локальное правило Windows NRPT для перечисленных в `VpnDnsPolicy.Names` доменов сервисов и их поддоменов. Прочие имена обслуживаются прежним DNS. Настройки DNS адаптеров и маршруты трафика не меняются. DoH/DoT следует маршрутизации Windows; прохождение всего трафика именно через VPN этой проверкой не доказывается. Список не обещает покрытие всех CDN, входа и всех функций каждого сервиса.

Перед включением проверяется шифрованный upstream. После добавления правила Windows выполняет некэшированный запрос к уникальному поддомену example.com. Включение подтверждается только если этот конкретный запрос замечен локальным DNS и системный вызов вернул ответ либо корректное отсутствие записи. Проверка повторяется каждые 30 секунд; отдельный чекер провайдера автоматически не запускается, поскольку вне списка доменов он может использовать DNS VPN. Надпись главного экрана подтверждает системный путь, а не генерацию модели.

Пересекающиеся правила VPN/организации, включая правило для всего DNS, не заменяются: включение отменяется. Перехват DNS VPN-клиентом или отдельный DoH браузера могут обходить NRPT. В таком случае потребуется настройка самого VPN/браузера. Режим не предоставляет раздельную маршрутизацию приложений и не выключает kill switch VPN.

Выключение, закрытие и аварийный выход удаляют только собственное правило. Перед применением запускается существующий отдельный процесс восстановления и записывается маркер с владельцем сессии. Следующая активация, очистка DNS и удаление программы также обрабатывают оставшееся правило. Если правило изменено извне или удаление не подтверждено, ошибка и ожидающее восстановление сохраняются. Смена активных интерфейсов/адресов останавливает сессию; после подключения другого VPN Smart DNS нужно включить заново.

Изменение галочки запрещено во время работы DNS. Способы 1 и 3 сохраняют прежний запрет VPN. Android не изменён.

Автоматические тесты используют фиктивные NRPT-правила и loopback на свободном порту. Реальная совместимость требует проверки с конкретным VPN-клиентом; тестовая сборка сама не переключает подключение пользователя.
