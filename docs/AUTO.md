# Режим «Авто · beta»

В Windows 2.23.6 Авто подбирает провайдера для Gemini, ChatGPT, Claude, ElevenLabs, Spotify или Antigravity. У сайтов и API отдельно проверяются DNS, соединение, TLS и HTTP. Проверки работают без ключей, входа в аккаунт и генерации ответа модели. Одновременно проверяются не более четырёх провайдеров; скрытые в настройках варианты не участвуют.

1. Выберите «Авто · beta» первым пунктом списка DNS.
2. Укажите сервис и нажмите «Подобрать DNS».
3. Просмотрите результаты и нажмите «Подключить …» или «Переключить на …».

Через Windows применяется выбранный системный DNS. В способе «Через приложение» Авто проверяет зашифрованные варианты с текущим DoH или DoT и запускает локальный обработчик. Если локальный DNS уже включён, прежнее подключение работает во время подбора; переключение происходит через тот же обработчик после проверки. Дополнительного запуска или запроса прав не требуется. Подтверждение обработчика одновременно обновляет провайдера и цель Авто на главном экране.

Отмена окна и отсутствие подходящего кандидата сохраняют подключение. Отказ нового провайдера сохраняет прежний DNS и прежний ручной/автоматический режим. Если сеть изменилась или DNS был остановлен во время подбора, старый результат не применяется и не включает DNS заново. Отдельный провайдер Antigravity сохраняется. При закреплённом отдельном Antigravity подбор основного DNS для этой же цели не подменяет проверку отдельного маршрута.

Можно выбрать сервис по умолчанию в настройках. Тогда большая кнопка запускает подбор для него. Ручной выбор провайдера временно переходит в ручной режим; сохранённая цель не стирается. Запуск программы сам по себе не включает DNS.

После подбора доступна кнопка «Копировать лог»: цель, результаты провайдеров, протокол, адреса, этапы DNS/TLS/HTTP и технические ошибки. В настройках можно сохранить журнал текущего запуска всей программы в TXT. Автоматической отправки журнала нет.

В системном режиме Windows раз в минуту проверяется только текущий провайдер и выбранная цель. При неудаче можно повторить подбор; программа не меняет DNS без действия пользователя. Локальный режим не переподключается автоматически после остановки или смены сети.

Авто остаётся **beta (нестабильный режим)**. Успешный ответ сайта не скрывает отказ или неопределённый ответ API. Явная проверка Cloudflare в браузере отображается отдельно; обычный HTTP 403 без такого признака автоматически не принимается. Проверка соединения и TLS не доказывает доступ к аккаунту или ответ ИИ. Собственный DNS браузера и отдельные ограничения сервиса могут влиять на результат. [Подробности проверки доступности](SERVICE-AVAILABILITY.md).
