# Режим «Авто · beta»

В **2.23.6-test.5** для Gemini, ChatGPT, Claude и ElevenLabs используется та же [проверка сайта и API без ключей](SERVICE-AVAILABILITY.md), что и в «Тест DNS». У каждого кандидата отдельно запрашиваются адреса сайта и API через выбранный DNS и протокол, проверяются соединение, TLS и HTTP-ответ. Одновременно работают не более двух HTTPS-попыток. Сайт с ответом 200 больше не скрывает отказ, региональное ограничение или неопределённый ответ API. Такой кандидат не выбирается. Запрос ключа/входа подтверждает ответ API, но не генерацию; проверка браузера показывается отдельно, варианты без неё получают приоритет. Для Spotify и Antigravity сохраняются прежние проверки доменов.

После успешного или неудачного подбора доступна кнопка **«Копировать лог»** рядом с результатами. Она копирует цель, результаты всех провайдеров и технические сведения: протокол, адреса, этапы DNS/TLS/HTTP, причины отказов и длительность. Ключи и токены очищаются, тела ответов API не включаются. Новая попытка или смена цели удаляет предыдущий лог из окна. Занятый буфер обмена позволяет повторить копирование без отдельного окна ошибки. Для копирования не нужно раскрывать результаты или сохранять файл.

Режим экспериментальный и помечен как нестабильный. При неудачном подборе можно выбрать провайдера вручную.

Режим доступен в стабильной Windows-версии **2.22.0**.

Подготовлено для следующей сборки: **⚙ Настройки → Сервис по умолчанию → Сохранить**. Выберите сервис, и кнопка включения будет сама запускать подбор и применять найденный DNS с обычным запросом прав Windows. Цель сохраняется после перезапуска. Выбор провайдера вручную временно возвращает ручной режим; сохранённый сервис не стирается. Чтобы отключить эту возможность, выберите в настройках «Ручной выбор DNS». Сохранение настройки само по себе не меняет сеть, подключения при запуске Windows нет. Неудачный или отменённый подбор не применяет DNS; успешная проверка соединения по-прежнему не подтверждает работу аккаунта или модели.

В следующем обновлении при ошибках подбора появится кнопка «Сохранить лог». Текстовый файл содержит версию, состояние сети, провайдеры и домены проверки, полученные адреса, попытки HTTPS, длительность и технические ошибки. Лог можно вручную отправить [@TotalCodeAdmin](https://t.me/TotalCodeAdmin). Автоматической отправки нет. При повторном подборе старые результаты для экспорта сбрасываются. Для отсутствия сети, включённого VPN и отмены запроса прав отчёт не предлагается. Такая же кнопка добавляется при сбое проверки DoH перед применением настроек.

1. В горизонтальном списке DNS прокрутите до «Авто».
2. Выберите одну цель: Gemini, ChatGPT, Claude, ElevenLabs, Spotify или Antigravity.
3. Нажмите «Подобрать DNS». Сначала проверяются DNS-ответы, затем HTTPS-соединение с адресами из этих ответов. Одновременно проверяются не более двух провайдеров.
4. Посмотрите короткий итог с выбранным DNS. Кнопка «Подключить Comss.one» (или другой выбранный провайдер) запускает применение с запросом прав Windows. Подробности скрыты под ссылкой «Результаты проверки».

При неудаче или отмене настройки не меняются. Escape и крестик не подтверждают подключение. Изменение цели сбрасывает предыдущий результат подбора. Если включён DoH, обычные DNS не используются; DNS-AI всегда проверяется и подключается с шифрованием.

Меняется **общий DNS компьютера**, а не настройки одного сайта. После подключения браузер или нужное приложение нужно перезапустить. Выбор обычного провайдера возвращает ручной режим. Цель «Авто» хранится в текущем запуске программы, без автоматического подключения при старте Windows.

В активном режиме раз в минуту проверяется только текущий провайдер и выбранная цель. При неудаче появляется статус «Проверьте Авто» и предложение повторить подбор. Программа не меняет DNS без действия пользователя и не показывает периодические всплывающие окна.

Проверка HTTPS подтверждает соединение и ответ сервера с проверкой TLS-сертификата. Она не входит в аккаунт и не запускает модель. Переадресация на вход не подтверждает возможность использовать сервис после авторизации; ответы 401/404/405 корня API Antigravity подтверждают только доступность его сервера. Региональные ограничения аккаунта, антибот-проверки и отдельный DNS браузера могут мешать работе даже при успешном тесте.

В `test.2` ответ Cloudflare с заголовком `cf-mitigated: challenge` отмечается как «проверка в браузере», а не как отказ DNS. Обычные успешные ответы получают приоритет. Если остались только варианты с браузерной проверкой, можно подключить предложенный DNS и открыть сервис в обычном браузере. Доступ к аккаунту при этом не считается подтверждённым. Ответ 403 без этого заголовка автоматически не принимается.

В `test.3` фон и свечение кэшируются в физических пикселях под текущий масштаб экрана. Это убирает дорогое масштабирование растров на каждом кадре, особенно при 200% DPI. Режим «Авто» и проверки Cloudflare сохранены.

Тесты подбора используют подставные ответы, не меняя DNS компьютера: `tests/AutoDns.Tests.cs`. Проверки окна и отмены: `tests/UiPerformance.Tests.cs`.

В 	est.4 окно подбора стало компактным: выбор сервиса сверху, короткий итог в карточке и одна основная кнопка. Во время проверки отображается число проверенных вариантов. Результаты всех DNS раскрываются отдельно и не закрывают кнопку подключения.

MagicDNS участвует в подборе для Gemini, ChatGPT, Claude и ElevenLabs, в обычном режиме и DoH. В Windows 2.23.3 добавлен подбор для Antigravity с проверкой обоих API-доменов. Для Spotify его кандидатура не добавлена. Xbox DNS отключён, цель Xbox скрыта из Авто и настроек. GeoHide и GeoHide EU исключены из всех целей Авто общим переключателем `enabled` в каталоге.
