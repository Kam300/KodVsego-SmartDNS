В наших сборочных скриптах нет .NET Reactor, UPX или другого обфускатора: EXE собирается системным C#-компилятором, установщик — Inno Setup с обычным сжатием LZMA2. Метка распознавателя Protector в отчёте не подтверждает, что соответствующий продукт применялся при сборке.

## Проверенные действия приложения

| Действие | Когда происходит | Назначение и ограничения |
| --- | --- | --- |
| Чтение адаптеров, DNS и правил Windows | При отображении состояния и проверках | Показ фактических настроек; WMI/CIM используются в том числе для DNS-политик |
| Запрос UAC | При применении или восстановлении DNS по действию пользователя | Запускается собственный EXE с ограниченной командой; локальный канал проверяет процессы клиента и сервера |
| Изменение DNS, правил Antigravity и привязки IPv6 | После запроса изменения и подтверждения прав | Состояние сохраняется для восстановления; выключение возвращает сохранённые параметры |
| Проверка GitHub | При старте и ручной проверке | Получение метаданных релиза. Автоматическая проверка не загружает и не запускает EXE |
| Скачивание и замена EXE | После нажатия «Обновить» | Только разрешённые HTTPS-адреса GitHub, проверка TLS, SHA-256, размера и версии; резервная копия и откат при ошибке запуска |
| Чтение параметров браузера | При запрошенном перезапуске браузера/Antigravity | Сохранение активных профилей. Браузер закрывается штатно, без Process.Kill; из командной строки заново формируются только разрешённые аргументы профиля |
| reg.exe export | При явном удалении известных старых правил Antigravity | Создание проверенной резервной копии двух конкретных правил перед удалением; скрытых PowerShell-скриптов для этого нет |
| SetDefaultDllDirectories | При запуске | Ограничение поиска системных DLL для защиты от подмены, не отключение защитных средств |
| Диагностический отчёт | По кнопке сохранения | Локальный файл, без автоматической отправки разработчику |

Целевой поиск по исходникам не выявил вызовов отключения Defender, добавления антивирусных исключений, Process.Kill, CreateRemoteThread, WriteProcessMemory или установки автозапуска через Run/RunOnce. Это ограниченный обзор исходников, а не полный независимый аудит всех зависимостей и поведения во всех средах.

Перечисленные действия могут объяснять часть общих поведенческих меток, но точный вклад в закрытые модели антивирусов по этим данным установить нельзя. Защитное ограничение DLL, проверка сертификатов и подтверждение UAC сохранены.

## Найденные проблемы и изменения в исходниках

1. В проверке запроса обновления допускалось только имя портативного EXE. Имя установленной программы `SmartDNS.exe` отклонялось. Теперь разрешены оба известных формата; произвольные имена по-прежнему запрещены. Проверки родителя, времени запуска, пути и исходного хеша сохраняются.
2. Перед запуском скачанного вспомогательного процесса повторно проверяются размер, версия и SHA-256 из сведений релиза. Изменённые байты не получают доверие через простое вычисление нового хеша.
3. Проверенный файл удерживается открытым без разрешения записи и удаления до подтверждения старта помощника. Добавлена проверка каталога подготовки и перенаправлений файла/папки. Само обновление не выполняется с правами администратора.

Это исправления надёжности и контроля целостности. Они не доказывают, что счётчики VirusTotal уменьшатся. В опубликованные 2.22.1 эти правки пока не входят.

## Проверки

- 40 проверок обновления: адреса, размеры, версии, хеши, именование установленной и портативной программ, отмена, замена и откат.
- Полный цикл на двух временных тестовых EXE: `KodVsego_SmartDNS.smoke.exe` и `SmartDNS.exe`.
- Изменение скачанного файла после вычисления ожидаемого хеша отклоняется до запуска помощника.
- На время подготовки запуска запись в проверенный пакет блокируется.
- После подтверждения помощник ждёт выхода только своего проверенного родителя, заменяет временный файл и перезапускает новую тестовую копию; старые байты сохраняются для отката.
- Рабочее приложение, DNS, антивирус и опубликованные релизы во время этих проверок не изменялись.

## Дальнейшие действия

Обращения производителям не отправлялись, повторное сканирование VirusTotal не запускалось, сертификаты не покупались. После следующей проверенной сборки можно повторно посмотреть отчёты и при необходимости запросить у срабатывающих производителей разбор возможного ложного срабатывания.

VirusTotal агрегирует чужие вердикты и рекомендует обращаться к их авторам: https://docs.virustotal.com/docs/false-positive.

Цифровая подпись подтверждает издателя, но не является гарантией отсутствия антивирусных детектов или предупреждений SmartScreen: https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation.
