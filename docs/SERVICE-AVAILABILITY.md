# Проверка доступности без ключей

В **2.23.6-test.7** в этом окне есть кнопка «Копировать»: она включает полный результат и технические детали, даже если они свёрнуты. Скопированный текст очищается от ключей и токенов. При смене сервиса/DNS и во время новой проверки прежний результат скопировать нельзя.

Windows 2.23.6-test.4: «Тест DNS» → сервис → провайдер → «Проверить». Протокол (обычный DNS, HTTPS или TLS) берётся с главного экрана. Результаты относятся к адресам, выданным выбранным провайдером, а не к текущему DNS браузера.

В 2.23.6-test.5 эти же проверки используются в [режиме «Авто»](AUTO.md) для четырёх ИИ-сервисов. Сначала подтверждается ответ сайта и API каждого кандидата. Явная блокировка, ошибка, лимит запросов и неопределённый ответ исключают кандидата; запрос входа или проверка браузера остаются условным результатом с явной подписью. Генерация не запускается.

Сайт и API проверяются независимо. Для каждого адреса видны этапы DNS, соединение, TLS и код HTTP. Проверяется сертификат исходного имени сервиса. Нет входа, чтения браузерных профилей, ключей, платной генерации или изменений сетевых настроек. Перенаправления не выполняются. Тест ограничен двумя параллельными целями и тремя адресами каждой цели; время HTTPS-попытки ограничено 12 секундами. Закрытие окна отменяет запросы. При обычном DNS ответ по-прежнему может быть перенаправлен сетевым оборудованием; шифрованный запрос подтверждает соединение с именем DNS-сервера.

Сервис может потребовать вход, API-ключ или проверку браузера. Это не сбой DNS. HTTP 403 без объяснения остаётся неопределённым. Региональная блокировка определяется только по явной причине в полях ошибки JSON API; упоминание страны на HTML-странице не используется. Ограничение частоты запросов и ошибка сервера показываются отдельно. HTTP 200 сайта подтверждает только ответ сайта; на API дополнительно требуется ожидаемая структура JSON. Ни один из этих результатов не подтверждает генерацию, состояние аккаунта или работу веб-приложения после входа.

Используются только GET-запросы к публичным адресам из документации:

| Сервис | Сайт | API без авторизации | Документация |
| --- | --- | --- | --- |
| Gemini | `gemini.google.com/` | `generativelanguage.googleapis.com/v1beta/models` | [Models](https://ai.google.dev/api/models#method:-models.list) |
| ChatGPT | `chatgpt.com/` | `api.openai.com/v1/models` | [List models](https://developers.openai.com/api/reference/resources/models/methods/list) |
| Claude | `claude.ai/` | `api.anthropic.com/v1/models` | [List models](https://platform.claude.com/docs/en/api/models/list) |
| ElevenLabs | `elevenlabs.io/` | `api.elevenlabs.io/v1/user` | [Get user](https://elevenlabs.io/docs/api-reference/user/get) |

Заголовок [`cf-mitigated: challenge`](https://developers.cloudflare.com/cloudflare-challenges/challenge-types/challenge-pages/detect-response/) отделяет проверку браузера от сетевого сбоя. Типичный отказ API без авторизации подтверждает только получение ответа сервера. Публичный API не заменяет проверку веб-версии ChatGPT, Gemini или Claude.

Тесты: `tests/ServiceAvailability.Tests.cs` — имитации сетевых этапов, ошибок авторизации, региональных ограничений, HTML вместо API, HTTP framing, отмены и ограничения размера ответа. `tests/UiPerformance.Tests.cs` — положение элементов, блокировка выбора во время проверки и сброс старого результата при смене цели в масштабах 100%, 150%, 200%.
