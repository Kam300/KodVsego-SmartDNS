# Каталог DNS-провайдеров

Windows и Android используют [config/providers.json](../config/providers.json). GeoHide и GeoHide EU временно отключены в Windows 2.23.3 и подготовленных исходниках Android 1.5.1.

MagicDNS поддерживает выбор для Antigravity, проверку обоих API-доменов и участие в Авто в обычном режиме и DoH. На Windows отдельная галочка Antigravity создаёт обычные DNS-правила только для `cloudcode-pa.googleapis.com` и `daily-cloudcode-pa.googleapis.com`. Для шифрования выберите MagicDNS, включите «Зашифрованный DNS» и подключитесь большой кнопкой: применяется общий DoH с обязательным HTTPS для обоих IP. Старые отдельные правила нужно предварительно отключить для полного шифрования. На Android MagicDNS доступен с DoH через существующий DNS VPN.

Адреса `109.120.132.43`, `94.249.177.102`, DoH `https://dns.magicdns.ru/dns-query` и заявленная поддержка Antigravity сверены с [сайтом MagicDNS](https://magicdns.ru/) 23 октября 2026 года. Наличие записи в каталоге не гарантирует доступ к аккаунту или модели.

Локальная сетевая проверка 23 октября: каждый из двух IP MagicDNS ответил через DoH на запросы обоих API-доменов Antigravity. HTTPS-проверка обоих доменов на каждом IP с исходным SNI и проверкой сертификата также прошла. Проверялись только DNS и соединение с API, без входа в аккаунт, запуска модели и перезапуска пользовательского Antigravity. Настройки сети при проверке не менялись.

GeoHide исключён из выбора, Авто и новых включений, в том числе через старые команды и отдельные правила Antigravity. Исторические номера и адреса оставлены для распознавания действующих настроек, отключения и восстановления резервных копий. Каталог встроен в программу: старые установленные версии не получают запрет удалённо, а уже применённые системные настройки не перезаписываются при запуске новой версии.

Чтобы добавить DNS, добавьте объект в конец массива. Минимальный пример ниже использует адрес из диапазона для документации, он не является рабочим DNS. Замените адрес и DoH на реальные. Обе платформы подхватят запись при следующей сборке.

```json
{"id":7,"key":"my-dns","name":"Мой DNS","ipv4":["203.0.113.53"],"doh":"https://resolver.example/dns-query"}
```

Обязательны только `id`, `key`, `name` и массив `ipv4`. По умолчанию запись включена, DoH отсутствует, шифрование не обязательно, IPv6 и списки сервисов пустые, тест проверяет `example.com`. IP для системного DoH Windows берутся из `ipv4`; при необходимости задайте отдельный `windowsDohServers`. Для участия в Авто добавьте `"autoGoals": ["Gemini"]` или другие подходящие цели.

| Поле | Значение |
| --- | --- |
| `id`, `key` | Постоянный номер и уникальный ключ. Старые записи нельзя удалять или переставлять: номера хранятся в настройках. |
| `name` | Название в интерфейсе. |
| `enabled` | `false` скрывает DNS из ручного выбора и Авто на обеих платформах. Восстановление уже применённых настроек остаётся доступным. |
| `ipv4`, `ipv6` | Массивы адресов обычного DNS. IPv4 обязателен; IPv6 может быть `[]`. |
| `doh` | HTTPS URL DoH или `null`, если шифрованного DNS нет. DoT и DoQ пока не поддерживаются. |
| `windowsDohServers` | IPv4 серверов для системного DoH Windows. Обычно повторяет `ipv4`, но у Comss отличается. Проверяйте адреса у провайдера. |
| `legacyIpv4` | Необязательный массив прежних полных наборов IPv4, например `[["194.87.196.13","186.246.49.127"]]`. Windows распознаёт их для восстановления. При новом подключении и в тестах они не используются. |
| `encryptedOnly` | `true` запрещает подключение этого провайдера через обычный DNS; требует `doh`. |
| `services` | Подписи сервисов на Android. |
| `autoGoals` | Для каких целей Windows предлагает провайдера в Авто: ChatGPT, Claude, Gemini, ElevenLabs, Spotify, Xbox, Antigravity. Можно `[]`. |
| `testHosts` | Домены для проверки ответов DNS. Не пустой массив. |
| `description` | Краткий список сервисов на главном экране Windows. |
| `site`, `url` | Название сайта и HTTPS ссылка провайдера. |

Один IPv4 тоже допустим: `"ipv4": ["203.0.113.53"]`. Этот адрес приведён только как пример, он не является рабочим DNS. Отсутствие DoH задавайте `null`, не пустой строкой.

Список сервисов — заявленная возможность провайдера, а не гарантия доступа. Добавление обычного публичного DNS не даёт обход ограничений само по себе. Отдельные правила Antigravity остаются специальной функцией с отдельной проверкой совместимости; новый DNS автоматически в эти правила не добавляется.

Генерация: Windows `build.bat` и `tests/run.ps1` запускают `tools/Sync-ProviderAvailability.ps1`; Android Gradle запускает `generateProviderAvailability`. Название скрипта сохранено для совместимости. Созданные `ProviderAvailability.cs` и `ProviderAvailability.java` вручную не редактируйте. Каталог включается в сборку; это не загрузка произвольных DNS из интернета во время работы.

Проверки отклоняют неверные адреса, не-HTTPS DoH, повторные ключи, изменение старых ID и отключение всех провайдеров. Для временного отключения достаточно изменить `enabled` и пересобрать обе платформы.

DNS-AI: актуальная пара `194.87.196.13`, `45.151.102.219` сверена 22 октября 2026 с [каталогом провайдера](https://github.com/confeden/DNS-AI/blob/main/endpoints.json), serial 7. Старый `186.246.49.127` оставлен только в истории для восстановления.

На ПК тесты и Авто проверяют DNS-AI через WinHTTP с HTTP/2 и исходным именем для TLS. При сетевом таймауте или отказе соединения неответивший адрес временно пропускается: сначала 30 секунд, затем 60, 120 и далее до 15 минут. Успешный ответ сбрасывает историю ошибок адреса. Смена сети и ручной запуск «Тест DNS» или подбора сбрасывают пропуски. Ошибки сертификата, HTTP и некорректные DNS-ответы не запускают переключение адресов. Настройки адаптера эта оптимизация не меняет.

Для выбора IP при сохранении имени TLS используется [WINHTTP_OPTION_RESOLUTION_HOSTNAME](https://learn.microsoft.com/en-us/windows/win32/winhttp/option-flags#winhttp_option_resolution_hostname), доступный с Windows 10 21H1. На более ранней поддерживаемой Windows остаётся обычное разрешение имени WinHTTP без отдельного пропуска адресов. Шифрование и проверка сертификата сохраняются.
