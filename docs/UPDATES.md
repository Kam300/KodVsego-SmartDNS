# Обновление программы

В стабильной Windows-версии **2.22.0** доступна проверка обновлений через стабильные релизы [Kam300/KodVsego-SmartDNS](https://github.com/Kam300/KodVsego-SmartDNS/releases), включая резервное подключение при нерабочем адресе API GitHub от выбранного Smart DNS.

При запуске проверка выполняется в фоне. Если доступна новая версия, рядом с номером версии внизу окна появляется стрелка. Проверить вручную можно нажатием на номер версии между «Код Всего» и ссылкой Telegram.

Нажмите «Обновить»: программа скачает EXE, проверит размер, SHA-256, название продукта и версию, затем закроется и запустит обновлённую копию. Настройки DNS, резервные копии сетевых настроек и тема сохранятся. Цель режима «Авто», как и раньше, выбирается заново после запуска.

Скачивание можно отменить крестиком или Escape. Без нажатия «Обновить» новая версия не устанавливается. Более старые версии и предварительные релизы не предлагаются. Для обновления запускайте приложение обычным способом, без прав администратора; права для изменения DNS запрашиваются отдельно.

Рядом с EXE сохраняется предыдущая копия с окончанием `.previous-<идентификатор>`. Если запуск новой версии завершается ошибкой непосредственно при старте процесса, установщик возвращает прежний файл. Проверка не гарантирует обнаружение ошибок, возникших уже после запуска приложения.

Программа остаётся переносимой: файл заменяется на месте, его имя сохраняется. У папки должна быть возможность записи; другие запущенные копии этого EXE следует закрыть. При отсутствии интернета проверка при запуске проходит без всплывающего сообщения; ручная проверка покажет ошибку и кнопку повтора.

При сетевой ошибке обычного HTTPS используется резервное подключение: адреса GitHub запрашиваются через DoH Cloudflare (`https://1.1.1.1/dns-query`). Системный DNS при этом не меняется. Соединение с GitHub сохраняет исходное имя сервера и штатную проверку TLS-сертификата. HTTP и отключение проверки сертификатов не используются. Перенаправления при скачивании по-прежнему ограничены официальными адресами GitHub. Это помогает при ошибочной подмене адреса GitHub выбранным Smart DNS, но не гарантирует работу при полной блокировке GitHub или Cloudflare.

Для выпуска обновления разработчик публикует стабильный релиз с тегом `vX.Y.Z` и файлом `KodVsego_SmartDNS.X.Y.Z.exe`. Версия продукта внутри EXE должна совпадать. Используется SHA-256 из сведений GitHub об asset; при отсутствии этого поля нужен `SHA256SUMS.txt` в том же релизе. Установщик принимает загрузки только из нашего репозитория и официального хранилища файлов GitHub по HTTPS.

Проверки: `tests/AppUpdate.Tests.cs` проверяет версии, адреса, контрольные суммы, разбор ограниченных по размеру HTTPS-ответов, замену файла и возврат старых байтов при ошибке запуска. `tests/UpdateInstall.Smoke.ps1` проверяет полный перезапуск на временных тестовых EXE, не меняя DNS и основной файл приложения. Отдельный сетевой тест `tests/UpdateNetwork.Smoke.ps1` собирает самостоятельный EXE с обычной защитой загрузки библиотек и проверяет получение метаданных и файла по резервному пути; скачанная программа не запускается.
