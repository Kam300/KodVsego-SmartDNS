# Карта сервисов · Windows и Android

Функция добавлена в актуальные исходники; существующие файлы GitHub Releases от изменения исходников не заменяются.

На Windows под адресами и значками сервисов находится заметная кнопка **«Карта сервисов»** с кратким итогом последней проверки. В карте строки соответствуют DNS, столбцы — сервисам. На Android отдельная карточка находится на главном экране рядом с состоянием подключения: **«Сравнить все DNS»** раскрывает список. По умолчанию выбран Gemini; можно выбрать другой сервис или «Все сервисы», а также обычный DNS, DoH или DoT. Нажатие **«Проверить все DNS»** запускает сравнение, второе нажатие останавливает его.

| Статус | Значение |
| --- | --- |
| Зелёный · Ответ получен | Получены ожидаемые ответы всех проверяемых endpoint. Это не проверка аккаунта или генерации. |
| Голубой · Нужен вход | Сервис ответил, но запрашивает вход или API-ключ. Это не отказ DNS. |
| Фиолетовый · Проверка браузера | Сервер требует пройти проверку в браузере. |
| Розовый · Есть проблема | Не удалось подтвердить DNS/HTTPS либо API сообщил об ограничении региона/ошибке сервера. |
| Не подтверждено | Например, неизвестный 403, ограничение частоты или неожиданный формат API. Не считается успешным доступом. |
| Не заявлено | Поддержка сервиса отсутствует в метаданных провайдера; сетевые запросы для этой ячейки не выполнялись. |
| Протокол недоступен | У провайдера нет выбранного режима; он не подменяется другим протоколом автоматически. |
| Не проверено / Не завершено | Проверка ещё не запускалась либо была отменена/не уложилась в общий срок. |

Нажмите на ячейку для деталей сайта и API, статуса HTTP и времени проверки. Изначально ни один DNS не помечен работающим. Выключенные в каталоге провайдеры не проверяются и не занимают строки основного сравнения. Карта учитывает все доступные встроенные DNS, в том числе скрытые пользователем из обычного переключателя. Пользовательские DNS Windows без заявленных сервисов остаются с нейтральным статусом.

Проверяются Gemini, ChatGPT, Claude, ElevenLabs и Spotify. На Windows дополнительно есть Antigravity и Xbox, если они заявлены доступными DNS; для Antigravity проверяются оба API-домена. Для Spotify и Xbox проверяется сайт, для четырёх ИИ — сайт и публичный API без ключа. Android не добавляет отдельную функцию Antigravity. Отсутствие публичного API-маршрута может дать «Не подтверждено» даже при рабочем приложении.

## Поведение и ограничения

- Проверка запускается пользователем и не меняет DNS Windows, настройки Android или активное подключение приложения. Запросы разрешаются именно через проверяемого провайдера, затем выполняется HTTPS с исходным именем и стандартной проверкой сертификата. Наличие DNS-ответа отдельно не даёт зелёный статус.
- В запросы не добавляются API-ключи, cookie или пользовательские данные, редиректы не выполняются. Проверяются только фиксированные адреса сервисов. Локальные и частные IPv4 из DNS не используются для HTTPS-проверки.
- Запросы выполняются ограниченной очередью: до четырёх проверок на Windows и трёх на Android, общий предел запуска — 120 секунд. Интерфейс обновляется по мере завершения. Незавершённые ячейки не получают успешный статус.
- У каждой завершённой ячейки есть время. При смене физической сети результаты сбрасываются. Изменение протокола также сбрасывает карту; каталог не применяется посреди проверки. Результаты относятся только к проверенной сети и протоколу.
- На Android уход приложения в фон отменяет незавершённые запросы. При пересоздании экрана результаты начинаются с «Не проверено». На Windows закрытие карты останавливает проверку и сохраняет уже полученные результаты в памяти до закрытия приложения; повторное открытие с другим каталогом/темой создаёт новую карту.
- Другой VPN может перехватывать соединения. При обнаруженном конфликте предлагается отключить его, а ячейки не помечаются работающими.

Сервис может менять доступность после входа в аккаунт, а браузер — использовать собственный DNS. Карта помогает сравнить текущие ответы провайдеров; доступ к аккаунту, регион аккаунта, подписка и генерация отдельно не проверяются.

## Проверка реализации · 28 октября 2026

Windows: прошли 540 проверок интерфейса, 44 проверки ответов сервисов, 66 проверок каталога и 22 проверки карты, включая светлую/тёмную тему, нейтральный начальный статус, недоступные протоколы, скрытие отключённых DNS и защиту соответствия строк при обновлении результатов. EXE собран. Реальная проверка Gemini через MagicDNS с DoT подтвердила HTTP 200 сайта и HTTP 403 API с требованием авторизации; DNS и сертификаты проверены, настройки сети не менялись.

Android: полный JUnit/Robolectric-прогон прошёл; после финального изменения повторены все 8 сценариев `ServiceHealthTest`, включая сброс старого зелёного результата при отсутствии сети. `lintRelease`: 0 ошибок, 20 предупреждений; release APK 1.5.2 / 9 собран с прежним сертификатом проекта и проверен через apksigner/zipalign. Телефон не подключён: реальная работа VPN, смена сетей и установка обновления на устройстве не проверены.

Начальный вид Windows просмотрен через computer-use; дальнейшую визуальную проверку пользователь остановил клавишей Esc. Последующие изменения компактности проверены компонентными тестами. Проверочные EXE и APK, суммы и журналы находятся локально в `dist/service-board/`; отдельный GitHub Release не публиковался.
