# Два варианта для Windows

## Без установки

`KodVsego_SmartDNS.<версия>.exe` запускается сразу. ZIP `KodVsego_SmartDNS.Portable.<версия>.zip` содержит тот же EXE, лицензии и краткую инструкцию. Распакуйте ZIP перед запуском.

Это вариант без установки, но не изолированное хранение всех данных на флешке: настройки и резервные копии остаются в Windows и общие с установленной версией.

## Установщик

`KodVsego_SmartDNS.Setup.<версия>.exe` устанавливает программу для текущего пользователя в `%LOCALAPPDATA%\Programs\KodVsego\SmartDNS`. Можно выбрать другую папку. Появляется ярлык в «Пуск»; ярлык на рабочем столе выбирается отдельно. Запуск после установки также выбирается пользователем.

Внутри папки EXE имеет постоянное имя `SmartDNS.exe`, поэтому ярлыки остаются действительными после обновления. Для установки права администратора не требуются. Изменение DNS выполняется через обычный отдельный запрос Windows.

Установщик не заменяет более новую версию старой в той же папке. Перед заменой используемого установленного EXE Windows может предложить закрыть приложение.

## Обновление и удаление

Встроенное обновление заменяет текущий EXE на месте в обоих вариантах. Сохранение оригинального отдельного файла `KodVsego_SmartDNS.<версия>.exe` в релизе обязательно: существующие версии ищут именно его, а не Setup или ZIP. Ярлыки установленной версии указывают на постоянное имя. Версия в списке установленных программ Windows обновляется при запуске установщика; после встроенного обновления актуальную версию смотрите в самой программе.

Удаление через настройки Windows убирает установленные файлы и ярлыки. DNS, настройки приложения и резервные копии не сбрасываются. Перед удалением выключите DNS в программе, если хотите восстановить прежние настройки сети. Так резервная копия не теряется при случайном удалении или переустановке.

## Сборка пакетов

Нужен Inno Setup 6.7 или новее из [официального источника](https://jrsoftware.org/isdl.php).

```powershell
.\build-distribution.ps1 -Compiler 'C:\path\to\Inno Setup 6\ISCC.exe'
```

Скрипт собирает приложение и пакеты в `dist\<версия>`. Параметр `-SkipAppBuild` использует готовый EXE с совпадающей версией. Путь компилятора можно задать через `INNO_SETUP_COMPILER`. Зависимость не скачивается автоматически.

Состав сборки:

- `KodVsego_SmartDNS.<версия>.exe` — без установки и для встроенного обновления.
- `KodVsego_SmartDNS.Setup.<версия>.exe` — установка.
- `KodVsego_SmartDNS.Portable.<версия>.zip` — архив без установки с инструкцией и лицензиями.
- `SHA256SUMS.txt` — контрольные суммы всех трёх файлов.

В релизе 2.22.1 публикуются два EXE: портативный и установщик. ZIP и SHA256SUMS.txt остаются дополнительными локальными результатами сборки. Контрольные суммы опубликованных файлов доступны в сведениях GitHub о файлах релиза; встроенное обновление проверяет SHA-256 EXE по этим сведениям. Тексты лицензий встроены в портативный EXE и дополнительно входят в установщик отдельными файлами.

Скрипт ничего не публикует на GitHub.

## Проверка

```powershell
.\tests\Packaging.Smoke.ps1 -Compiler 'C:\path\to\Inno Setup 6\ISCC.exe'
```

Проверка собирает отдельный установщик с уникальным AppId, именами ярлыков и временной папкой. Проверяются установка, совпадение байтов с портативным EXE, ярлыки, регистрация Windows, повторная установка и удаление. Приложение не запускается, DNS не меняется. Тестовая регистрация и ярлыки удаляются; журналы остаются во временной папке.
