# Варианты для Windows

Начиная с Windows 2.23.2 основной установщик — **MSI**. Стандартный набор также содержит портативный ZIP и отдельный EXE, нужный существующим версиям для обновления. Установщик EXE через Inno Setup исключён из стандартной сборки. Ранее опубликованные релизы сохраняют прежний состав.

## Установка через MSI

`KodVsego_SmartDNS.Setup.<версия>.msi` устанавливает приложение для текущего пользователя в `%LOCALAPPDATA%\Programs\KodVsego\SmartDNS-MSI`. Создаются ярлык **Smart DNS (MSI)** в меню «Пуск» и запись в списке установленных приложений Windows. Требования: Windows 10 2004+ / Windows 11, x64, .NET Framework 4.8.

Перед установкой или обновлением закройте Smart DNS. Установщик не запускает приложение и не меняет DNS. Права для изменения DNS программа запрашивает отдельно. Более старый MSI блокируется; повторный запуск установленного пакета предлагает восстановление файлов или удаление.

MSI использует отдельную папку и сохраняет прежнюю установку через EXE. Настройки приложения и резервные копии общие. При переходе на MSI прежнюю копию можно удалить через настройки Windows; выключать DNS для самого перехода не требуется. [Подробности MSI, порядок версий и проверки](MSI.md).

## Без установки

`KodVsego_SmartDNS.Portable.<версия>.zip` содержит EXE, пять файлов лицензий и инструкцию. Распакуйте архив и запустите программу. Отдельный `KodVsego_SmartDNS.<версия>.exe` содержит то же приложение; тексты лицензий также встроены в него.

Настройки и резервные копии хранятся в Windows и общие с установленной версией. Это не отдельный профиль на флешке.

## Обновление и удаление

MSI-копия проверяет новые версии, но кнопка обновления открывает страницу релиза. Для установки нужен новый MSI. Автоматическая загрузка и запуск MSI пока не реализованы.

Портативные версии и прежние установки через Inno Setup сохраняют обновление EXE на месте. В каждом релизе обязательно оставлять отдельный файл `KodVsego_SmartDNS.<версия>.exe`: существующий механизм проверки новых версий ищет его. ZIP и MSI его не заменяют.

MSI 2.23.2 при окончательном удалении автоматически восстанавливает прежнюю сеть с подтверждением Windows, затем удаляет настройки программы, кэш, файлы и ярлыки. При ошибке восстановления удаление останавливается, оставшиеся копии сохраняются. Обновление через MSI не запускает очистку. Подробности и ограничения — в [инструкции MSI](MSI.md). Сохранённые пользователем отчёты и экспортированные копии правил не удаляются. Для портативной версии и прежних EXE-установок по-прежнему сначала выключите DNS вручную.

## Сборка стандартного набора

Нужны подписанный Microsoft Roslyn из Visual Studio / Build Tools, .NET SDK и WiX CLI 5.0.2. Inno Setup для стандартной сборки не нужен. [Подготовка WiX](MSI.md#сборка).

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-distribution.ps1
```

Результат находится в `dist/<версия>/release`:

- `KodVsego_SmartDNS.Setup.<версия>.msi` — основной установщик.
- `KodVsego_SmartDNS.Portable.<версия>.zip` — портативный архив.
- `KodVsego_SmartDNS.<версия>.exe` — запуск без установки и совместимость с обновлениями.
- `SHA256SUMS.txt` — SHA-256 всех трёх пакетов.
- `release-files.json` — точный список файлов, их ролей, размеров и контрольных сумм.

Приложение собирается один раз проверяемым Roslyn-процессом; тот же EXE входит в MSI и ZIP. Состав готового EXE дополнительно проверяется без запуска приложения. Отчёты компиляции, исходные материалы MSI и файлы WiX остаются в отдельной папке `packaging-<идентификатор>`, рядом с папкой релиза.

Параметры:

- `-Wix <путь>` — путь к WiX CLI 5.0.2.
- `-AppCompiler <путь>` — путь к подписанному Microsoft Roslyn.
- `-SourceExe <путь>` — упаковать готовый EXE с совпадающей версией, сохранив его байты.
- `-SkipAppBuild` — использовать готовый EXE из корня проекта; можно сочетать с `-SourceExe`.
- `-OutputDirectory <папка>` — другая папка результата.

Скрипт отказывается перезаписывать существующие файлы релиза или смешивать новый набор с оставшимся установщиком EXE. Для повторной сборки выбирайте новую папку либо повышайте версию. Проверенные VirusTotal файлы от этого не изменяются. Параметр прежнего сборщика `-Compiler` для Inno Setup больше не используется.

В релиз включаются три пакета и метаданные из `release`, ориентируясь на `release-files.json`. Файл `Setup.<версия>.exe` туда не входит. Скрипт ничего не публикует на GitHub и не загружает файлы в VirusTotal.

## Проверки

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Distribution.Tests.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\MsiPackaging.Tests.ps1
```

Первая проверка собирает стандартный набор во временной папке, проверяет список пакетов и SHA-256, состав ZIP, структуру MSI, отсутствие установщика EXE и защиту ранее собранных файлов от перезаписи. Также проверяется упаковка уже готового EXE. Приложение не устанавливается и не запускается.

Вторая проверка испытывает установку, восстановление, обновление, запрет понижения версии, сбой обновления и удаление на отдельном семействе безвредных тестовых EXE. Рабочая копия Smart DNS и настройки DNS не меняются.
