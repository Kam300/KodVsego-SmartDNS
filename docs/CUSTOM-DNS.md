# Свои DNS в Windows

Откройте **Настройки → DNS-провайдеры → + Добавить DNS**.

- Название — до 48 символов.
- IP-адреса — 1–4 IPv4, дополнительно до 4 IPv6; разделитель: пробел, запятая или новая строка.
- DoH — необязательный HTTPS-адрес на порту 443, например `https://resolver.example/dns-query`.
- DoT — необязательное имя TLS-сервера, например `resolver.example`; используется порт 853.
- «Участвует в Авто» разрешает проверять DNS при подборе для сервисов. Это не утверждение о поддержке сервисов.
- Поддержку отдельного Antigravity нужно отметить явно; для неё необходим DoH.

Нажмите «Готово», затем **«Сохранить»** в настройках. Запись сразу появится на главном экране; подключение само не включается. «Отмена» в настройках отбрасывает все несохранённые добавления, правки и удаления. Изменение и удаление доступны кнопкой **…** у своей записи. Встроенные записи здесь не редактируются.

Используемую запись нельзя редактировать или удалять до отключения DNS. Скрытие галочкой разрешено и не выключает подключение. Для измерения задержки новой или изменённой записи сначала сохраните настройки.

Список хранится в профиле Windows, в значении `CustomDnsProviders` ключа `HKCU\SOFTWARE\KodVsego\SmartDns`. Он не попадает в общий каталог приложения, Android или GitHub. ID своих записей находятся в диапазоне 64–95, отдельно от встроенных. Удалённая запись скрывается, но её ID и адреса остаются для распознавания прежних настроек и не присваиваются другому провайдеру. Лимит — 32 записи с учётом сохранённой истории.

DoH с логином, паролем, параметрами запроса, фрагментом или нестандартным портом не поддерживается. Для своих DNS нет встроенного официального чекера: общая проверка рекурсивных узлов не подтверждает, что выбранный провайдер используется без перехвата.
