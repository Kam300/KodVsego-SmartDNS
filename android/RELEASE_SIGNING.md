# Подпись Android-релизов

Application ID: `ru.kodvsego.smartdns`.

Первый Android APK 1.0.0 подписан сертификатом проекта с SHA-256:

```text
6F:9D:E6:76:12:CE:DA:D4:04:63:93:E9:B9:48:54:53:68:96:DF:5D:0A:83:C6:F9:EE:63:C2:0E:B2:D9:6F:0E
```

Проверить сертификат APK можно командой `apksigner verify --print-certs FILE.apk`.
Контрольная сумма файла APK отличается от отпечатка сертификата и публикуется
отдельно в `SHA256SUMS.txt` вместе с файлами релиза.

Ключ выпуска и пароли находятся только на машине сборки, исключены из Git.
Для выпуска обновлений владельцу проекта нужно сохранить ключ и параметры
подписи из расположений, указанных в [инструкции](README.md#подпись-apk).
CI debug-сборки подписываются другим, отладочным сертификатом.
