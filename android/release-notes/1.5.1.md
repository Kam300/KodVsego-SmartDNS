# Код Всего · Android 1.5.1 — каталог провайдеров и проверки DNS

- Обновлён резервный адрес DNS-AI: `45.151.102.219`. DNS-AI по-прежнему использует только DoH.
- Провайдеры, адреса, DoH и домены тестирования берутся из общего с Windows каталога `config/providers.json`.
- Разработчик может временно отключить провайдера в каталоге перед сборкой. Новая версия скрывает его в списке и выбирает доступный DNS вместо сохранённого отключённого варианта. Номера остальных провайдеров и настройки виджетов сохраняются. Удалённого отключения без обновления APK нет.
- Уточнены домены проверок сервисов. GeoHide и GeoHide EU включены в этом выпуске.
- Сохранены встроенная проверка обновлений, темы, виджеты и настройки приложения.

Android 8.0+, пакет `ru.kodvsego.smartdns`, версия `1.5.1`, versionCode `8`. Для обновления поверх 1.5.0 требуется прежний ключ подписи проекта.

Пользователи 1.5.0 смогут найти обновление в приложении. При переходе с 1.4.1 и более старых версий APK нужно установить вручную. Настройки сохраняются; после обновления DNS может потребоваться включить снова.

Проверки подготовки: 87 JUnit/Robolectric-тестов прошли, Android Lint release — без замечаний, release APK собран. Реальная установка обновления и работа VPN на телефоне в ходе подготовки не проверялись. Android-версия остаётся предварительной.
