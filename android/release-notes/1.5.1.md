# Код Всего · Android 1.5.1 — каталог провайдеров и проверки DNS

- Обновлён резервный адрес DNS-AI: `45.151.102.219`. DNS-AI по-прежнему использует только DoH.
- Провайдеры, адреса, DoH и домены тестирования берутся из общего с Windows каталога `config/providers.json`.
- Разработчик может временно отключить провайдера в каталоге перед сборкой. Новая версия скрывает его в списке и выбирает доступный DNS вместо сохранённого отключённого варианта. Номера остальных провайдеров и настройки виджетов сохраняются. Удалённого отключения без обновления APK нет.
- Добавлена заявленная поддержка Antigravity у MagicDNS и проверка обоих API-доменов. Доступен обычный DNS и DoH.
- GeoHide и GeoHide EU временно отключены: их нельзя выбрать или включить в этой версии.
- Сохранены встроенная проверка обновлений, темы, виджеты и настройки приложения.

Android 8.0+, пакет `ru.kodvsego.smartdns`, версия `1.5.1`, versionCode `8`. APK собран из коммита `eb45aa3705f50f2cff7600d310439e9ecc0e4166` и подписан прежним ключом проекта: сертификат совпадает с опубликованным APK 1.5.0.

Пользователи 1.5.0 смогут найти обновление в приложении. При переходе с 1.4.1 и более старых версий APK нужно установить вручную. Пакет, подпись и схема хранения настроек сохранены; удалять приложение перед обновлением не нужно. После обновления DNS может потребоваться включить снова. Сохранённый GeoHide или GeoHide EU заменяется доступным провайдером.

Проверки выпуска: 88 JUnit/Robolectric-тестов прошли без ошибок и пропусков, Android Lint release — без замечаний; проверены подпись APK, версия, пакет и выравнивание. Отпечаток SHA-256 сертификата: `6f9de67612cedad4046393e9b94854536896df5d0a83c6f9ee63c20eb2d96f0e`.

Подключённого телефона нет. Установка поверх 1.5.0 с сохранением настроек, реальное включение/выключение DNS и переход Wi-Fi → мобильная сеть → Wi-Fi в обычном режиме и DoH на устройстве не проверены. Автоматические тесты не заменяют эти проверки. Android-версия остаётся предварительной; Windows остаётся основным latest-релизом.
