# Android 1.5.2 — подготовка обновления после Windows 2.23.8

`versionName=1.5.2`, `versionCode=9`. Предыдущая опубликованная Android-версия — 1.5.1 / 8. Специальные функции Antigravity в Android не добавлялись.

## Что подготовлено

- Актуальный общий каталог: Zapret DNS, GeoHide US, Malw DNS, WLrus DNS, Webshift, AdGuard DNS и Malw CF; исторические ID сохранены. GeoHide RU/EU и Xbox остаются отключены.
- DoH и DoT, IP из общего каталога, проверка имени и цепочки сертификата. При сетевой ошибке зашифрованный режим не переходит на обычный DNS.
- Проверенная смена провайдера/протокола без остановки TUN: до окончания проверки работает прежняя конфигурация. Остановка/отзыв разрешения отменяют ожидающий результат.
- Видимость каждого провайдера, ссылки на информационные сайты и измерение задержки. Скрытие не отключает текущую сессию; оставить нужно хотя бы один видимый DNS.
- Авто-подбор по ответу DNS и задержке. Опциональная автосмена после трёх ошибок, максимум раз в минуту и три попытки за десять минут. Текущий провайдер можно проверить через другой зашифрованный протокол. Восстановление прежнего DNS, выключение опции и скрытие выбранного кандидата отменяют отложенное применение.
- Копирование результатов и выгрузка собственного журнала через системный выбор файла. Два приватных файла журнала ограничены примерно 256 КиБ каждый; ключи и параметры URL очищаются. Имена пользовательских DNS-запросов и чужие журналы не сохраняются. Автоматической отправки нет.

Авто — beta. DNS-ответ не гарантирует доступ к сайту, аккаунту, региональную доступность или ответ ИИ. APK требует прогона на настоящем телефоне: Wi-Fi/мобильная сеть, DoH/DoT, активная смена, отмена VPN и экспорт. Unit/Robolectric и lint не заменяют эти проверки.

## Для второго разработчика

1. Получить подготовленные исходники. Создать локальные `local.properties` и `signing.properties` по существующему примеру. Ключи и пароли в Git не добавлять.
2. Использовать **прежний ключ проекта**, которым подписана Android 1.5.1. Новый debug-ключ не подходит для обновления.
3. В каталоге `android` выполнить:

```powershell
.\gradlew.bat testDebugUnitTest lintRelease assembleRelease --no-daemon --no-watch-fs
```

4. Проверить `applicationId=ru.kodvsego.smartdns`, `versionName=1.5.2`, `versionCode=9` и сертификат:

```powershell
apksigner verify --verbose --print-certs app/build/outputs/apk/release/app-release.apk
```

Ожидаемый SHA-256 сертификата прежнего ключа:

```text
6F:9D:E6:76:12:CE:DA:D4:04:63:93:E9:B9:48:54:53:68:96:DF:5D:0A:83:C6:F9:EE:63:C2:0E:B2:D9:6F:0E
```

5. Проверить установку **поверх 1.5.1** без удаления приложения, сохранение настроек, VPN и виджеты. Затем переименовать подписанный APK в `KodVsego-SmartDNS-Android-1.5.2.apk`, вычислить SHA-256 и опубликовать Android-релиз `android-v1.5.2` с APK и `SHA256SUMS.txt`.

Если `signing.properties` отсутствует, Gradle создаёт `app-release-unsigned.apk`. Это **не готовое обновление**: его нельзя выдавать за подписанный релиз. В тестовом `assemblePreview` package — `ru.kodvsego.smartdns.test`, версия `1.5.2-test.12`, другая подпись; он предназначен для отдельной установки.

## Каталог DNS без переустановки

В настройках добавлен «Обновлять адреса DNS автоматически»: проверка раз в сутки, ручная проверка и сохранённая рабочая копия. Работающее подключение не меняется. Общий формат, ревью изменений сайтов и публикация описаны в [REMOTE-CATALOG](../docs/REMOTE-CATALOG.md). Удалённая проверка заработает после публикации `config/catalog.json` в основной ветке.
