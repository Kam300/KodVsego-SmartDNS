# Android 1.5.2 — подготовка обновления

Каталог от 25 октября дополнен Zapret DNS, GeoHide US, Malw DNS, WLrus DNS, Webshift, AdGuard DNS и Malw CF. GeoHide RU/EU и Xbox по-прежнему отключены. Источники и ограничения: [новые DNS](../docs/PROVIDER-SOURCES-2026-10-25.md). Для Webshift и Malw CF шифрование обязательно; Android использует их DoH через существующий DNS VPN.

`versionName=1.5.2`, `versionCode=9`. Xbox DNS отключён общим каталогом: отсутствует в выборе, не запускается через сохранённый старый intent; сохранённый выбор заменяется доступным провайдером. GeoHide и GeoHide EU остаются отключёнными. Исторические ID не изменены; остановка прежнего сеанса остаётся доступна.

Для установки поверх опубликованной 1.5.1 нужен прежний ключ подписи проекта. Разработчику с ключом: получить текущие исходники, выполнить `testDebugUnitTest lintRelease assembleRelease`, подписать APK прежним ключом, проверить package `ru.kodvsego.smartdns`, версию 1.5.2 / 9 и сертификат, затем выпустить отдельный Android-релиз. Подготовка исходников сама по себе не обновляет установленные APK.
